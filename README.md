# sovereign-meet (working name, provisional)

**EU-sovereign video conferencing, Jitsi-inspired.**

Jitsi Meet is excellent, open-source, WebRTC-based technology — but it's been owned by **8x8 (a US company)** since 2018, despite being born at Inria (France). For anyone who needs video infrastructure that is actually governed in the EU, not just historically founded there, that's a real gap.

This project starts from Jitsi Meet's own codebase (Apache 2.0 — permits this) and is working toward real architectural and governance independence, not staying a thin re-skin.

## Status: early, deliberately unfinished

This is not a finished product. It's a starting scaffold and an invitation. If "EU-owned video infrastructure" is something you care about, this needs contributors more than it needs polish right now.

## Governance

Intended to be governed by **Powerworks Foundation**, a nonprofit vehicle being set up in Ireland specifically so this isn't owned by any single commercial entity — the same sovereignty argument made against Jitsi's current ownership would apply to a single company owning "the EU-sovereign alternative." That legal entity does not exist yet as of this repo's creation (2026-11-02) — this repo is seeded ahead of that paperwork, under the Powerworks-Global GitHub org temporarily, and will move once the Foundation's own org exists.

## What's actually decided so far

- Fork Jitsi Meet (Apache 2.0) as the technical starting point rather than build WebRTC from scratch.
- Hosting location (Beelink vs. AWS) not yet decided.
- No product name chosen yet — "sovereign-meet" is a repo placeholder, not a brand.

## Contributing

Open to contributions from day one. If you want to help figure out what "EU-sovereign" should actually mean architecturally (not just who signs the invoice), open an issue.
